O que é o PETAlerta?

O PETAlerta é uma proposta de sistema voltada para o monitoramento de animais em período pós-operatório dentro de clínicas veterinárias.

A ideia surgiu a partir da identificação de uma dificuldade enfrentada durante o acompanhamento dos animais. Os profissionais precisam realizar verificações frequentes, mas uma alteração pode acontecer entre uma verificação e outra.

Para ajudar nesse processo, o PETAlerta propõe o uso de câmeras, visão computacional e inteligência artificial. As imagens dos animais podem ser analisadas pelo sistema para identificar possíveis alterações de comportamento.

Quando o sistema identifica uma situação que merece atenção, a proposta é gerar um alerta para que o profissional possa verificar o animal.

Como funciona?

Câmeras captam as imagens → o sistema analisa os movimentos → possíveis alterações geram um alerta para a equipe.

Objetivo

O objetivo do PETAlerta é auxiliar a equipe veterinária no acompanhamento dos animais, contribuindo para um monitoramento mais contínuo e organizado durante o período pós-operatório.

Tecnologias utilizadas

A proposta utiliza câmeras, visão computacional e inteligência artificial para analisar as imagens dos animais e auxiliar na identificação de possíveis sinais de dor ou desconforto.
